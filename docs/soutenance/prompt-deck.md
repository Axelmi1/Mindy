- **Onboarding 9 étapes** : accroche → niveau → domaine → objectif → temps/jour → quiz démo (crédite les premiers XP) → résultat → inscription (email+mot de passe) → génération du parcours.
- **Monétisation Stripe (freemium)** : **Free 0 $** (5 leçons/jour, série basique, classement standard, défi quotidien) · **Pro 9,99 $/mois** (leçons illimitées, parcours perso IA, analytics avancées, 10 streak freezes, sans pub) · **Pro annuel 79,99 $/an** (~−33 %, 2 mois offerts, accès anticipé, export PDF).
- **Back-office analytics** : DAU/WAU/MAU, rétention D1/D7/D30, funnel signup→Pro, export CSV.
- **Stack** : monorepo TypeScript de bout en bout — API **NestJS** (REST + Swagger, validation Zod, ORM Prisma), mobile **Expo/React Native** (Zustand, Reanimated), **PostgreSQL serverless (Neon)**, **Stripe** + webhooks, **Expo Push** + emails Resend, auth **JWT + bcrypt** (guard global sécurisé par défaut). Déploiement continu : **un `git push` = API sur Render + OTA mobile EAS Update**. 🆕 **~365 tests Jest** backend. Testable par n'importe qui via **Expo Go (QR code)**.
